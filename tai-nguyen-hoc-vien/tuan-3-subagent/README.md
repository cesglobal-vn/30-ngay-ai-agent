# Tài nguyên học viên - Tuần 3

## Buổi 11 - Skill làm sạch dữ liệu

Tất cả file nằm trong `buoi-11-skill-lam-sach-du-lieu/`.

| File | Gửi khi nào | Nội dung |
|---|---|---|
| `buoi-11-skill-lam-sach-du-lieu.md` | Đầu buổi | **File chính phát cho học viên** - đủ 7 câu lệnh copy-dán từ mở file tới đóng gói skill, làm trong khoảng 15 phút, không có phần thảo luận (để dành thời gian giảng viên) |
| `buoi-11-skill-lam-sach-du-lieu.docx` | Đầu buổi | Bản Word cùng nội dung, tiện in/gửi |
| `buoi-11-don-hang-2026-ban-a.csv` + `.xlsx` | Đầu buổi | **File làm bài** - 500 dòng, 21 cột, đã gieo lỗi |
| `buoi-11-don-hang-2026-ban-b.csv` + `.xlsx` | Cuối buổi | File thứ hai, dùng chứng minh skill chạy lại được bằng 1 câu |

Đáp án lỗi đã gieo (số lượng, mã đơn từng loại) nằm ở `giao-an/tuan-3-subagent/buoi-11-dap-an-loi-da-gieo.md` - **chỉ dành cho giảng viên**, dùng để đối chiếu khi học viên báo kết quả.

> File `buoi-11-dap-an-skill-lam-sach-du-lieu.docx` (bản cũ, nội dung 10-bước trước khi rút gọn) nay đã lỗi thời so với `buoi-11-skill-lam-sach-du-lieu.md` - có thể xóa khi dọn thư mục.
